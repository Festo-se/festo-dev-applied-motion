    axis_protocol

    axis_protocol

    Structural protocol that all axis backend implementations must satisfy.

    Axis

    Bases: Protocol

    Structural interface for a single controllable axis.

    Both EdconAxis (Modbus/festo-edcon backend) and FPosBAxis (FPosBAPI backend) satisfy this protocol structurally — no explicit inheritance required.

    All position values are in millimetres (mm). All velocity values are in mm/s.
